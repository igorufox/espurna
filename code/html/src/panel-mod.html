Parts of the firmware that live in the free flash behind the head: switch them on while there is room.

The modules are off: .
The guard switched them off so the board stays reachable. Fix what they need (or switch the heavy ones off), then start them again.
Memory
Yellow: almost everything is taken, the board still runs. Point at a module that is off to see what it would take (striped).
Modules
The modules come from espurna-esp8266-1m-modules.bin or the full image espurna-esp8266-1m-full.bin of the release this board runs: from the disk, or From GitHub. On: the module is written into the free flash; off: it is taken out. Both apply at the next restart. Without the webui module the board keeps a small page with the same switches, modules.html.
