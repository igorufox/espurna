OLED

The small I2C screen of the board (SSD1306 / SH1106): what it shows is in the SCREEN panel

Panel and pins
on the I2C bus, 0x3c or 0x3d
the I2C bus of the board (the i2c module), shared with the I2C sensors
the pin that holds the panel in reset (Heltec WiFi Kit 32: GPIO16), none if it has none
The controller, size, address and pins apply after a reboot of the board when the bus changes.
